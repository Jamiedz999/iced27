# ICED27 Instructions for Authors

> Converted from `ICED27_Instructions_for_Authors (1).docx` (the official Word template).
> The `.docx` remains the source of truth for actual formatting — papers MUST be written in that template.
> Names in `「」` are Word style names defined in the template; apply them, never manual formatting.

## Quick checklist

- [ ] Paper is based on the official, unmodified ICED27 template (template is protected)
- [ ] A4, 25 mm margins; **max 10 pages** including acknowledgements, references and appendices
- [ ] No custom headers/footers, no page numbers
- [ ] Title written manually, 「Title」, sentence case, no full stop
- [ ] No author names, affiliations, keywords or abstract in the paper; metadata placeholder untouched
- [ ] Headings in sentence case, no full stop, levels 1–3 only
- [ ] No blank lines between paragraphs of main text
- [ ] Every table/figure/equation cited in text before it appears
- [ ] Table captions above tables; figure captions below figures; no full stop in captions
- [ ] APA 7th references, alphabetical, DOI included where available, cited ↔ listed match exactly
- [ ] All comments deleted, all tracked changes accepted/rejected, no markup
- [ ] First submission: PDF only. Camera-ready: PDF **and** DOCX
- [ ] Submitted via ConfTool with abstract (≤ 900 characters) and 3–5 keywords (≥ 3 from predefined list, ≤ 2 free)

## 1 Introduction

- Guide for submissions to the **26th International Conference on Engineering Design (ICED27)**.
- Proceedings are produced in Microsoft Word, so papers must be properly formatted using the official template.
- The template is used for both the **first** and **camera-ready** submissions.
  - First submission (before review): **PDF only**.
  - Camera-ready: **PDF and DOCX**.
- Before submission: delete all comments, accept/reject all tracked changes, no markup.
- Submit exclusively via **ConfTool** (see conference website). In the first step you submit:
  - an abstract of **max 900 characters**;
  - **3–5 keywords**: at least 3 from the predefined list, up to 2 of your own choice.
- The template is protected and must not be modified. Papers based on another template or a modified template are returned for reformatting.

## 2 Paper format

- Page size A4 (210 × 297 mm), 25 mm margins → text area 160 × 247 mm.
- Length limit **10 pages**, including acknowledgements, reference list and appendices. No additional pages accepted.
- No custom headers or footers. Do not add page numbers.

## 3 Metadata

- Replace the "Enter paper title here" placeholder with the paper title in **sentence case**.
- Do **not** insert author details, keywords or abstract anywhere in the paper. They are added to the metadata placeholder during typesetting.
- Do not edit or delete the metadata placeholder (the table at the top of the template: "Metadata placeholder (please do not edit or delete)").
- In ConfTool, write repeated entries (e.g. author names/institutions across multiple papers) identically everywhere.

## 4 Formatting requirements

Use the predefined styles only. Style properties are listed in [Appendix B](#appendix-b--style-reference).

### 4.1 Title

- Written manually at the top of the first page.
- Style 「Title」, sentence case, no trailing full stop.

### 4.2 Headings

- All headings in sentence case, no trailing full stop.
- Level 1 → 「Heading1」, level 2 → 「Heading2」, level 3 → 「Heading3」. These are **automatically numbered** (do not type numbers).
- Do not use heading level 4 or lower.
- Unnumbered headings (Acknowledgement, References, Appendix …) → 「Unnumbered heading」.

### 4.3 Main text

- Style 「Normal」. No blank lines between paragraphs.
- Bold → character style 「Strong」; italic → 「Emphasis」; bold+italic → 「Intense Emphasis」.
- Use SI units throughout (e.g. 100 mm, 10 kN, 30 N/mm²).

### 4.4 Lists

Three predefined list styles; preferably no more than three levels.

| List type | Style | Notes |
|---|---|---|
| Bulleted | 「Bulleted list」 | dot bullets |
| Numbered | 「Numbered list」 | automatic numbering, starts with an ordinal number |
| Lettered | 「Lettered list」 | automatic lower-case letters, alphabetical |

### 4.5 Tables

- Caption **above** the table, style 「Table caption」, no trailing full stop. Inside a caption use soft returns only (Shift+Enter).
- Tables centred on the page. Cell text: 「Table text left」, 「Table text right」 or 「Table text centre」.
- Default table header is bold. In cells use 「Strong」 / 「Emphasis」 / 「Intense Emphasis」 for bold / italic / bold-italic.
- Preferably do not split a table across pages.
- Cite each table in the main text before it appears (e.g. "Table 1").
- A table can be built in a separate document and pasted into the template.
- If a text paragraph follows a table, leave **one blank line** between them. Not needed if followed by a heading, figure or another table.

### 4.6 Figures

- Inline with text, centred, paragraph style 「Figure」.
- No text boxes over figures. Avoid inserting graphical (drawing) objects as figures; insert from file via "Insert pictures".
- Resolution **300 dpi or higher** (quality cannot be improved during typesetting).
- Caption **below** the figure, style 「Figure caption」, soft returns only, no trailing full stop.
- Cite each figure in the main text before it appears (e.g. "Figure 1").
- Authors must secure copyright permissions for any reused artwork they don't hold the copyright to.

### 4.7 Equations

- Style 「Equation」: left-aligned with 1.27 cm left indentation; equation number at the right margin.
- Press Tab to move from the equation to the number. Numbers are entered **manually**, e.g. `(1)`.
- Cite each equation in the main text before it appears (e.g. "Equation 1").
- In-text subscript/superscript → character styles 「Subscript」 / 「Superscript」.

### 4.8 Direct quotes

- Block quote: inside quotation marks, style 「Quote」.
- In-text quote: may remain in 「Normal」 with character style 「Emphasis」, inside quotation marks.

### 4.9 Footnotes

- Avoid footnotes. If used, footnote text style 「Footnote Text」.

## Acknowledgement

- Optional. Placed **before** References, heading in 「Unnumbered heading」.

## References

Citation style: **APA 7th edition** (supported by EndNote, Mendeley, Zotero, Citavi, etc.).

### In-text citations

| Case | Parenthetical | Narrative |
|---|---|---|
| 1 author | (Smith, 2022) | Smith (2022) suggests… |
| 2 authors | (Smith & Jones, 2023) | Smith and Jones (2023) argue… |
| 3+ authors | (Smith et al., 2024) | Smith et al. (2024) found… |
| Direct quote | (Smith et al., 2024, p. 15) | — |

### Reference list

- Heading in 「Unnumbered heading」; each entry in style 「References」.
- Every in-text citation must appear in the list and vice versa.
- Sorted **alphabetically**.
- Include the **DOI** whenever the publication has one (find via source website or https://www.crossref.org).
- More examples: https://apastyle.apa.org/style-grammar-guidelines/references/examples

#### Patterns and examples

**Journal papers** — Author(s). (Year). Title of article. *Title of Periodical*, *volume*(issue), pages. DOI or URL.

**Book chapters** — Author(s) of chapter. (Year). Title of chapter. In Editor(s) (Ed(s).), *Title of book* (pp. pages). Publisher. DOI or URL (if available).

**Theses** — Author. (Year). *Title of thesis* [Type of thesis, Name of Institution]. Database Name. DOI or URL (if available).

## Appendix A — Appendices rules

- Optional. Placed **after** References, heading in 「Unnumbered heading」 (no numbering).
- Labelled with letters: Appendix A, Appendix B, … and referenced the same way in text (e.g. "Please consult Appendix A for …").
- Count toward the 10-page limit.
